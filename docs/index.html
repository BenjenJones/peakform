Everything your watch records, put to work.

Garmin collects a lot of data. PeakForm puts it in one place and shows how sleep, stress, recovery and training affect each other.

Daily readiness

A 0–100 score from HRV, resting HR, sleep and stress, measured against your own 60-day baseline, not population averages.

Training load

Fitness, fatigue and form (CTL/ATL/TSB) and the acute:chronic ratio, from Garmin's training load or Banister TRIMP.

Activities in detail

Original FIT files decoded into per-second HR, power, speed, altitude and GPS. Route maps, laps, replay and side-by-side comparison.

Performance curves

Mean-max power and HR curves and aerobic decoupling, so you can see whether endurance is actually improving.

Insights

A lagged correlation matrix: does a late workout cost you HRV the next night? Does stress show up in your sleep score?

Multi-user

Everyone in the household brings their own Garmin key and sees only their own data. In Home Assistant, sign-in happens through HA.

Up and running in minutes

You need a Garmin Connect Personal API key from Garmin Connect (web) under Settings → Personal API Key.

Home Assistant

  1. Settings → Apps → App store → ⋮ → Repositories
  2. Add https://github.com/BenjenJones/peakform
  3. Install PeakForm for Garmin and start it
  4. Open PeakForm in the sidebar, paste your key under Account
Add repository to Home Assistant

Docker

# clone and start
git clone https://github.com/BenjenJones/peakform
cd peakform
openssl rand -base64 32 > master_key.txt
docker compose up -d --build
# open http://localhost:8099

Put it behind a TLS reverse proxy before you expose it to the internet.

PeakForm for Garmin macht aus deinen Garmin-Daten einen täglichen Readiness-Score, Trainingsbelastung (Fitness, Ermüdung, Form), HRV-, Schlaf- und Stresstrends und eine detaillierte Auswertung jeder Aktivität aus der Original-FIT-Datei, mit Karte, Runden und Leistungskurven.

FAQ

What do I need?

A Garmin Connect account and a Personal API key, created in Garmin Connect (web) under Settings → Personal API Key. Plus Home Assistant or any machine that runs Docker.

Where is my data stored?

In a single SQLite file on your server. PeakForm talks only to Garmin and, if you turn on reviews, to Anthropic or OpenAI.

Do activity reviews need a Claude or ChatGPT subscription?

No, they use an API key with credit, from the Claude Console (Anthropic) or the OpenAI platform, a few cents per review. A Claude Pro/Max or ChatGPT Plus/Pro subscription cannot be used for this. Reviews are optional.

Can I move from Home Assistant to Docker later?

Yes. Take the database from a backup of the app and start the Docker container with it. The README has the steps.
